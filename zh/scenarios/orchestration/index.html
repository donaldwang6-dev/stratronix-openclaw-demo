SCENARIO 02

定时任务编排

7 个定时任务散落在 4 台机器上。一次静默失败就把整条链路打断。OpenClaw 把它合并成一条 DAG — 自带重试与告警。

复杂度下降
7→1
7 个 cron → 1 个 DAG

改造前

# 4 台机器上 7 个 cron，靠人脑记依赖

- id: orders_pull
  cron: 0 2 * * *
  host: db-01

- id: ads_pull
  cron: 0 3 * * *
  host: db-02

- id: ads_etl
  cron: 0 4 * * *
  host: etl-01

- id: support_pull
  cron: 0 5 * * *
  host: db-01

- id: etl_merge
  cron: 0 6 * * *
  host: etl-01

- id: report_pdf
  cron: 0 7 * * *
  host: etl-02

- id: report_send
  cron: 0 8 * * *
  host: etl-02

retry: exp(2s, 30s, 5m)

改造后

# 一条 DAG，依赖自动解析

- id: daily_pipeline
  trigger: cron(0 2 * * *)
  steps:
    - id: orders_pull
      next: [ads_pull, support_pull]
    - id: ads_pull
      next: [ads_etl]
    - id: ads_etl
      next: [etl_merge]
    - id: support_pull
      next: [etl_merge]
    - id: etl_merge
      next: [report_pdf]
    - id: report_pdf
      next: [report_send]
    - id: report_send
    retry: exp(2s, 30s, 5m)
▸ 失败自动重试
任何一步失败都会按指数退避重试 3 次，不必半夜爬起来。
▸ 静默失败可观测
所有节点记录耗时、状态、错误码。一旦偏离基线立刻告警。
▸ DAG 依赖清晰
节点拓扑一眼看明白，串改不破坏依赖。
